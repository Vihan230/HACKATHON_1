LEVEL 1

Merge Sort — Station Ordering

The first stage of network reconstruction involves sorting station identifiers in the correct order using the Merge Sort algorithm.

How It Works

Station IDs are converted to numeric values based on ASCII values of their letters. Merge Sort is used to arrange them in ascending order while measuring the disorder level by counting inversions during the merge phase.

Sample Stations & Values

Station ID Letter 1 (ASCII) Letter 2 (ASCII) Sum (Value)
RC 82 67 149
QA 81 65 146
BT 66 84 150
FM 70 77 147
PE 80 69 149

Why Merge Sort?

Merge Sort is ideal for counting inversions (disorder level) with O(n log n) efficiency. This helps identify how corrupted the network ordering has become.

Topological Sort Algorithm

LEVEL 3

Network Reconstruction — Minimum Spanning Tree

Reconstruct the network with minimal cost while maintaining full connectivity. Using a weighted connectivity matrix, we identify the optimal connections.

The Challenge

We need to minimize total network cost while ensuring all stations are connected and no cycles exist (forming a tree structure).

Weighted Connectivity Matrix (-1 = No Connection)

From/To RC QA BT FM PE CU
RC 0 5 -1 8 -1 12
QA 5 0 7 -1 10 -1
BT -1 7 0 6 -1 9

PE -1 10 -1 4 0 3

What This Matrix Shows

Positive values: Connection cost between stations
-1: No possible connection (network constraint)
0: Self-reference (no cost to same station)

Minimum Spanning Tree Concept

Goal: Minimize Cost, Avoid Cycles

Kruskal's Algorithm finds the optimal set of connections:

  • Sort all edges by weight (cost)
  • Add edges one by one if they don't create a cycle
  • Stop when all stations are connected
  • Result: Minimum total cost with full connectivity
